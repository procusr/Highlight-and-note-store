# Quick Setup Guide

## Instant Setup (30 seconds)

1. **Extract**: Unzip all files to a folder
2. **Launch**: Double-click `index.html` 
3. **Use**: Click any learning pathway to get AI prompts

## How to Use AI Prompts

1. **Select Pathway**: Click on a learning pathway card (🔍 🧪 💪 🔧 🔗)
2. **Enter Topic**: Type your subject (e.g., "Python Programming", "Spanish Grammar")
3. **Customize**: Click "Customize" to personalize the prompt
4. **Copy**: Click "Copy Prompt" button
5. **Paste**: Use in ChatGPT, Claude, or any AI assistant
6. **Learn**: Follow the AI coach's personalized guidance!

## What Each File Does

- **index.html** - The main app interface (open this first!)
- **app.js** - All the interactive functionality + AI prompts
- **style.css** - Beautiful styling with dark/light modes
- **aggregated.md** - Research sources for learning methods
- **README.md** - Detailed documentation
- **DOCUMENTATION.md** - Complete technical guide

## Troubleshooting

**Can't see the interface?** 
- Make sure all files are in the same folder
- Try opening index.html in a different browser

**AI prompts not working?**
- Make sure to customize with your topic first
- Copy the entire prompt text
- Some AI assistants work better than others

**Need help?**
- Check DOCUMENTATION.md for detailed explanations
- All features work offline - no internet required for the main app

Enjoy your enhanced learning experience! 🚀
