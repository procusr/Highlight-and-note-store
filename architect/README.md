# Learning Architect - AI-Enhanced Educational Platform

Transform your learning experience with evidence-based cognitive science and AI-powered personalized coaching.

## 🚀 Quick Start

1. **Download**: Get all files in the ZIP package
2. **Open**: Launch `index.html` in your web browser  
3. **Explore**: Navigate through the five learning sections
4. **Access AI Prompts**: Click any learning pathway to get personalized AI coaching prompts
5. **Customize**: Enter your topic and copy prompts to use with any AI assistant
